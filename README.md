# Исследование стартапов и инвестиционных направлений

## О проекте

Анализ данных о стартапах, объёмах привлечённого финансирования, рыночных сегментах и возврате средств инвесторам.

Цель проекта — исследовать структуру рынка стартапов, динамику финансирования и различные типы инвестиций, чтобы определить перспективные направления для вложения средств.

## Задачи

- подготовить и очистить данные о компаниях и финансировании;
- исследовать структуру рынка стартапов;
- сегментировать компании по длительности финансирования;
- выделить массовые, средние и нишевые сегменты рынка;
- выявить аномальные объёмы финансирования;
- проанализировать динамику инвестиций по годам;
- определить наиболее перспективные растущие сегменты;
- сравнить различные типы финансирования;
- проанализировать динамику возврата средств инвесторам;
- сформулировать рекомендации по выбору отрасли и типа финансирования.

## Что сделано

Исходный датасет содержал 54 294 записи о компаниях и их финансировании.

В ходе предобработки:

- приведены к единому виду названия столбцов;
- денежные значения преобразованы в числовой формат;
- даты преобразованы в `datetime`;
- обработаны пропуски и текстовые значения;
- удалены дубликаты и записи без данных о финансировании;
- заполнены пропуски в датах финансирования.

После очистки осталось 40 907 записей — 75,3% исходных данных.

Для дальнейшего анализа компании были сгруппированы по длительности финансирования, а рыночные направления разделены на массовые, средние и нишевые сегменты.

Для выявления аномальных значений использовался метод межквартильного размаха (IQR).

## Основные результаты

### Длительность финансирования

58,9% компаний получили только один раунд финансирования.

30,1% компаний привлекали финансирование более одного года, а 11% — в течение периода до года.

При этом на компании с финансированием сроком до года пришлось 61,9% общего объёма инвестиций.

### Структура рынка

После исключения неопределённых значений было выделено 394 рыночных сегмента:

- 289 нишевых;
- 57 средних;
- 48 массовых.

Несмотря на большое количество нишевых направлений, около 88% компаний сосредоточены в массовых сегментах.

### Анализ финансирования

Распределение объёма финансирования имеет сильную правостороннюю асимметрию.

Медианный объём привлечённого финансирования составляет около 2,1 млн долларов.

По методу IQR верхняя граница типичных значений составляет около 24,4 млн долларов. Более крупные объёмы финансирования рассматривались как аномальные и дополнительно анализировались внутри отдельных сегментов рынка.

### Перспективные направления

Наиболее заметный рост объёмов финансирования наблюдался в сегментах:

- Software;
- Enterprise Software;
- Finance.

Software лидировал по объёму привлечённых инвестиций на протяжении большей части анализируемого периода, а Finance демонстрировал уверенный рост в последние годы.

### Типы финансирования

`venture` лидировал по объёму привлечённых средств и был одним из наиболее распространённых типов финансирования среди компаний.

`angel` и `seed` показывали высокие значения доли возвращённых средств, однако их показатели значительно колебались от года к году.

`venture` показал более стабильную динамику возврата средств среди рассмотренных типов финансирования.

## Вывод

По совокупности результатов наиболее перспективным направлением для инвестирования в рамках проекта оказался сегмент Software.

Дополнительный потенциал показали Enterprise Software и Finance.

Для инвестирования в Software рекомендовано `venture`-финансирование: оно сочетало большой объём рынка, высокую распространённость среди компаний и более стабильную динамику возврата средств.

## Запуск проекта

### Системные требования

Для локального запуска потребуется:

- Python 3.x;
- Jupyter Notebook;
- библиотеки pandas, NumPy, Matplotlib и Seaborn.

Установить необходимые библиотеки можно командой:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### Локальный запуск

Склонируйте репозиторий:

```bash
git clone https://github.com/NatashaBass/startup-investment-analysis.git
cd startup-investment-analysis
```

Запустите Jupyter Notebook:

```bash
jupyter notebook
```

Откройте файл `startup_investment_analysis.ipynb`.

Для полного повторного выполнения анализа необходимы исходные датасеты проекта. При локальном запуске пути к файлам данных в notebook могут потребовать изменения в соответствии с их расположением на вашем компьютере.

Отдельного развёртывания приложения не требуется.
